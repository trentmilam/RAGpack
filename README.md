# RAGpack (archived)

This repo is archived. The code lives in [agentic-rag/packages/ragpack](https://github.com/trentmilam/agentic-rag/tree/main/packages/ragpack), and that is where new work happens.

RAGpack turns documents into a searchable Qdrant vector store, with optional GPU embeddings and
optional GPU OCR.

It moved because agentic-rag and chain-rag both use it for ingestion.

Its commit history up to the move went with it.
